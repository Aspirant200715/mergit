# Contract ABIs

Generated from the interfaces in [`mergit-contracts`](https://github.com/mergit-io/mergit-contracts) by
`chain/abi/sync.sh`. Do not edit the JSON files or `frontend/src/chain/abi.ts` by hand; change the interface in
`mergit-contracts`, then run:

```bash
chain/abi/sync.sh            # expects mergit-contracts next to this repository
```

If your Foundry cannot download the compiler, point it at a local one with `FOUNDRY_SOLC=$(which solc)`.
