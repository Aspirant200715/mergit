# spec

The contracts between the parts of Mergit. Both teams build against these files, so a change here is a
reviewed change.

| File | What it fixes |
| --- | --- |
| [`receipt-v0.md`](receipt-v0.md) | Receipt structure, hashing, Merkle root, signature, verification reason codes |
| [`predicate-v0.md`](predicate-v0.md) | The outcome predicate `Φ` in v0 and when it holds |
| [`events-v0.md`](events-v0.md) | Events between the orchestration service and the web3 services |
| `schemas/` | JSON Schemas (2020-12) for every object above |
| `examples/` | One valid instance per schema, and invalid ones under `examples/invalid/` |
| `vectors/` | Test vectors generated by the Rust receipt crate; every implementation must agree with them |
| `src/` | The `mergit-spec` crate: types and hashing shared by the builder and the verifier |

Run `bash spec/check.sh` to validate the examples against the schemas.
